# Dokkanalytics
Dokkanalytics is a website created to calculate unit stats (ATK & DEF) for the mobile game Dragon Ball Z: Dokkan Battle.

The website also features a guide created by @razzdokkan on Twitter to familiarize yourself with how the calcing logic actually behaves, thought it's not necessary.
Included is also a "Calculator Guide" which I HIGHLY recommend, both with a blaring white circle and arrow on the website, and here in text form, that you read.
Future plans are to expand the site to also include calculating probabilities (eg. Chance of Dodging an X amount of attacks, Chance of launching an Additional Super)

Use it, enjoy it.
