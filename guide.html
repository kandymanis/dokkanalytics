Calculator Guide

Field reference for the ATK and DEF calculators.

For a full explanation on how ATK/DEF calculation works, see Razzer's Calcing Guide.

General

• It's pronounced Dough-can-uh-lytiks

• All empty fields are automatically taken as 0

• All percentage fields take the total buff percentage for that bracket, not a multiplier. For example, a dual +220% leader skill is entered as 440

• All fields support arithmetic, you can type 200÷5+15x5 or (5*20+100)/2 and it evaluates automatically

• The copy button next to the result copies the raw unformatted number to your clipboard, ready to paste into a damage calculator

• Calculation steps are shown below the result in real time, showing each bracket's intermediate value

• The collapsible HiPo Stats Guide panel shows the flat ATK/DEF stat bonuses added to base stats from the Hidden Potential system. Useful when the Dokkan Twitter account posts a new unit with their stats at 0% HiPo

• Clicking the + icon next to the result copies your current calculation to the SA List. Click the reset icon inside the list to clear it

ATK Fields

FieldInput
Base ATK Stat The unit's raw ATK at max level, before any multipliers.
Skill Orb Stats Flat ATK from HiPo skill orbs. Added to base before multiplication.
Leader Skill (%) Combined ATK% from both leaders. A dual +220% lead = 440.
Phase 1 / SoT Buffs (%) All ATK% buffs active before the first attack of the turn.
Domain Effect (%) ATK% from a Domain/Territory.
Support Items (%) ATK% from Support Items/Memories.
Link Skills (%) Total ATK% from all activated link skills.
Active Skills (%) Total ATK% from all Active Skill effects.
Ki Multiplier (%) The unit's Ki Multiplier at their launched Ki. Find on DokkanInfo or DokkanDB.
Phase 2 / Mid-Battle (%) ATK% buffs that trigger during battle, "When Attacking", etc.

SA Configuration

FieldInput
Rarity TUR or LR. Determines available SA types.
SA Type Most common SA Types.
EZA'd Check if the unit is EZA'd. Raises the base SA multiplier.
Manual Check for manual input of SA Multiplier
HiPo SA Boost Level of the SA Boost Hidden Potential node. Each level = +5%. Level 6 = +30%, level 15 = +75%. Defaults to 15 (rainbow).
SA Effects (%) ATK% from SA effects, e.g. a previous super's "raises ATK by X% for Y turn(s)." or an ally's SA support.
Finish Multiplier Only visible when SA Type is Finish. Enter the base multiplier of the Finish/Active Skill plus charge counts for standby's, e.g. 750+2000 for a 100 charge count 8th Anni PHY Buu Bro's standby.

DEF Fields

FieldInput

Skill Orb Stats Flat DEF from HiPo skill orbs. Added to base before multiplication.
Leader Skill (%) Combined DEF% from both leaders. A dual +220% lead = 440.
